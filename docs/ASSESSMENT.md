## 1. 動作・費用（事実）

- **ローカル実行は原則すべて無料**。有料API・トークン・課金サービスへの依存は
  コード全体で皆無（地図は Mapbox ではなく MapLibre + 地理院タイル、トークン不要）。
  - データ: GSI衛星SAR・KSJ土地利用・地理院DEM/タイル・OSM・MLIT陥没・地理院
    ジオコーディング — すべて公的オープンデータ。
  - ソフトウェア: Django/PostGIS/React/MapLibre/deck.gl/GeoPandas 等すべてOSS。
- **注釈（「無料」の限界）**:
  - 自マシンの計算資源・電気代はかかる。クラウド公開デプロイは課金対象
    （README もデプロイはスコープ外と明記）。
  - OSM Overpass API は無料だがコミュニティ運営でレート制限あり。本格運用では
    自前 Overpass 等が必要。
  - 地理院タイル・各データには利用規約（出典明示、大規模/商用時の条件）がある。

## 3. 社会貢献の評価（事実に基づく主観的所見）

### 貢献しうる面
- **課題は本物**: 八潮市陥没（2025）を受けた MLIT の緊急点検要請に対し、限られた
  予算・人員での点検優先順位づけは実在するニーズ。
- **「ラストマイル」の着眼は妥当**: 公開されているが自治体が使える形になっていない
  InSAR 生データを、地図＋トリアージへ翻訳する参照実装としての実用価値がある。
- **誠実性の枠組み自体が貢献**: できること・できないことを明示し、否定的な統計結果
  （仮説不支持）すら隠さず公開する姿勢は、地理空間分析の提示方法の"お手本"として
  教育的価値がある。過大主張の多い「AIハザード予測」への counter-example。
- オープンソース＋実データ＋再現可能であり、他者が学び拡張できる。

### まだ届いていない面（公開前に自覚すべき事実）
- **Triage の優先度は道路長との順位相関 ρ=0.903**。現状の優先度は実質「道路長の
  地図」に近く、"道路が多い所を見よ"以上の独立した意思決定価値は未実証
  （プロジェクト自身も明記）。
- **中核仮説（陥没箇所は沈下が強い）は統計検定で支持されず**（片側p=0.962）。
  沈下シグナルが予測価値を足す証拠は本AOIでは得られていない。
- **管路は合成データ（Illustrative）**。実自治体が自分の管路にそのまま使えない。
- **原理的限界**: InSAR の分解能（数十m）ではマンホール単位を分離できず、最も危険な
  「八潮型の突発的・局所的陥没」はそもそも予兆検知できない。

### 公開についての結論
- **コード・手法のオープンソース公開**: ネットにプラス。過大主張がなく再現可能で、
  disclaimer が徹底されているため害のリスクが低い。
- **公開する作品として**: 検出科学と競合せず補完する位置づけで筋が通っており、
  「実データで誠実なGIS意思決定層を作れる」技術力と知的誠実さの証明として説得力が
  ある。ただし **"製品"ではなく "PoC"** として提示するのが正直。
- **一般向け"全世界公開"の注意点**: 実在都市の上に「点検候補 高/中/低」を色分け表示
  すると、disclaimer があっても一般市民・メディアに「この地域は危険」と誤読される
  コミュニケーションリスクがある。不特定多数向けなら、この枠をさらに前面に出す配慮が要る。

## 4. 総括

**「検証済みのハザード予測製品」としては社会に出せる段階ではないが、「公開衛星データを
自治体の意思決定に橋渡しする誠実なPoC・参照実装」としては公開する社会的価値がある。**
最大の資産は新規の予測能力ではなく、"何を主張でき何を主張できないか"を厳密に示した
知的誠実さそのものである。それを隠さず「PoC」と位置づけて出す限り、社会貢献に
つながると評価する。
